This is my personal website.

I want to use this website as a creative playground of sorts; a way for me to learn about programming *(React, web technologies, and also general software design patterns and approaches)*, while also being able to express myself and have fun. 

This is just a passion project. I have no end goal in mind, but I do have an ever-updating list of ideas that I want to get implemented.

Expect bugs, expect jank, expect it all; but also expect me to keep at it and forever polish and improve this website.

So, please enjoy. There's not much now, but hopefully you can see the vision.

## File Structure
Code is split into folders based on category. I've added `README` files to each important directory, so travel along to learn more

## Building and running
This is a standard `React` app, so expect the normal commands:
- `npm run dev` - For running the dev environment
- `npm run build` - For building the production code
- `npm run lint` - For running the linter
- `npm run preview` - For running the production environment

I also included a custom command for me
- `npm run dev-windows-env` - Opens `VS Code`, splits the terminal into two panes (20% and 80% width), and launches the dev environment (in the smaller pane)
    - I use `Windows Terminal`, so I think this only works with that
    - And also only works if you use `VS Code` as your IDE
